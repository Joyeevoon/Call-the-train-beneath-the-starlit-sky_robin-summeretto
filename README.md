# 星穹列车 · Honkai: Star Rail

一个可以玩的夜空动画网页：流星雨不停落进一圈圈的水面，点击召唤星穹列车，再点列车让它变身、放银河烟花，全程有 BGM 伴奏。

## 怎么玩

**第 1 次点击（点画面任意处）— 召唤列车**
星穹列车从画面左下方斜着冲出来，一路擦着水面溅起水花，最后停在画面中央轻轻浮着。

**第 2 次点击（点列车本体）— 极光苏醒**
整列车变成蓝→粉→紫的极光渐变色，车顶少女也跟着一起变色。同时两条银河星带环绕列车旋转，一群星星围着它闪烁。

**第 3 次点击（再点列车）— 银河烟花**
几发烟花从车上射出去升空，先炸开成圆球，停顿半秒，再从每一朵的边缘往下淌成蓝粉紫的瀑布流光，落进水面还会荡起涟漪。之后每点一次列车，就再放一轮。

**随时可玩的小互动**
- 一直有流星雨落下：落到水面会溅起飞舞的蝴蝶和星星，星星再落回水里会激起小涟漪。
- 点击空白的夜空或水面，会有一道流星落在你点的位置。
- 水面会倒映列车、银河、烟花和流星，倒影随水波晃动。
- 车顶坐着的少女来自参考图的高清重绘，两种状态下发色都会跟随列车变化。

**右上角两个圆按钮**
- 音符按钮：开 / 关背景音乐（音乐会在你第一次点击画面时开始）。
- 循环箭头按钮：重玩一次，清空列车和所有特效，回到最初的星空。

## 建议玩法顺序

召唤列车 → 盯着流星雨和蝴蝶看一会儿 → 点列车看极光变身 → 再点一次看烟花瀑布 → 心满意足后按重玩，从头再来一遍。

## 适合

- 手机竖屏和电脑横屏都能玩（会自动适配）。
- 当动态壁纸、氛围页，或者发给朋友比拼谁点的烟花好看。

---

技术栈是 p5.js + Blender 渲染贴图，纯静态页面无需联网加载（p5.js 与素材均内置），下载后双击 `index.html` 即可离线游玩。
